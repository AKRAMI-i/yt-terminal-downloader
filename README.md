# YT Terminal Downloader

A lightweight YouTube downloader for Windows CMD, built with Python, yt-dlp, and Rich.

## Features

- Download videos with selectable maximum resolutions.
- Extract audio as MP3.
- Preview video information before downloading.
- Display download progress, speed, and estimated time remaining.
- Remember your preferred download folder.
- Maintain local download history.
- Detect missing FFmpeg installations.
- Use a clean terminal interface.

## Requirements

- Python 3.10 or newer
- FFmpeg for MP3 conversion and merging separate video/audio streams
- Internet connection

## Installation

Install Python and Git, then run:

```bash
py -m pip install git+https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

Replace `YOUR_USERNAME` and `YOUR_REPOSITORY` with your GitHub username and repository name.

Then start the application:

```bash
yt
```

## Usage

Choose an option from the terminal menu and follow the prompts.

Downloads are saved to your configured folder. Configuration and download history are stored locally in your user directory.
